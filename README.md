# Trabalho de Banco de Dados - Consultas SQL (DQL)

Repositório criado para armazenar a resolução das 25 questões práticas de consulta de dados (**DQL**) utilizando **PostgreSQL**.

## Estrutura do Repositório

* `dql_parte 1.sql`: Arquivo contendo todos os comandos SQL comentados de acordo com a numeração das questões.
* `README.md`: Apresentação simples do trabalho.

## Tabelas Utilizadas

As consultas foram realizadas sobre a seguinte base de dados:

* `fato_vendas`
* `dim_cliente`
* `dim_produto`
* `dim_loja`

## Como Executar

1. Importe e popule as tabelas no seu ambiente **PostgreSQL**.
2. Abra o arquivo `dql_parte 1.sql` no seu gerenciador de banco de dados (pgAdmin, DBeaver, etc.).
3. Execute as consultas individualmente ou em bloco para visualizar os resultados.
